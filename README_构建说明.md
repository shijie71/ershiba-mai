# 「二十八脉」安卓 App 构建与安装说明（红米/小米专用·原生振动）

## 为什么需要这个 App
你用红米 K80 在网页里点"摸脉"不震动，是因为 **小米 HyperOS 在系统底层封死了网页振动**（权限列表里也找不到"振动"开关，任何开关都救不了）。
这个 App 用**安卓原生方式**直接驱动手机马达，小米无法屏蔽，**100% 能真震动**。

> 你拿到的是一套"安卓工程源码"，需要一次免费云端构建，产出 `app-debug.apk`，装到手机即可。
> 整个过程不用装任何开发软件、不用懂代码。

---

## 第一步：拿到 APK（二选一，推荐方法 A）

### 方法 A：GitHub 免费云端构建（最简单，不用装软件）
1. 注册/登录 GitHub：https://github.com （用邮箱即可，免费）。
2. 新建仓库：点右上角 **＋ → New repository**，名字随便（如 `ershiba-mai`），**仓库选 Public**（私有也行，但 Public 最简单），其余默认，点 **Create repository**。
3. 上传工程：进到新仓库，点 **Add file → Upload files**，把电脑上 `_28mai_apk` 文件夹里的**全部内容**（注意是整个文件夹里的东西，包括 `app/`、`build.gradle`、`settings.gradle`、`.github/` 等）**拖进去**。
   - 直接拖整个 `_28mai_apk` 里的文件和子文件夹即可，GitHub 会保留目录结构。
4. 提交：页面底部填个说明（如 `init`），点 **Commit changes**。
5. 等构建：点仓库顶部的 **Actions** 标签 → 会出现一条正在跑的流水线（叫 `Build APK`）。点进去看进度，**等几分钟**到绿色 ✓。
6. 下载：构建完成后，页面下方 **Artifacts** 里有个 `app-debug-apk`，点它下载，得到一个 `app-debug.apk`。

### 方法 B：自己电脑装 Android Studio 构建（备选，较慢）
1. 下载安装 Android Studio（https://developer.android.com/studio，约 1GB+）。
2. 打开 Android Studio → Open → 选电脑上的 `_28mai_apk` 文件夹。
3. 等它自动下载 SDK 和依赖（首次较慢，需联网）。
4. 菜单 **Build → Build Bundle(s) / APK(s) → Build APK(s)**。
5. 完成后右下角提示，点 **locate** 找到 `app-debug.apk`。

---

## 第二步：把 APK 装到红米手机
1. 把 `app-debug.apk` 传到手机：用 **微信文件传输助手**（发给自己）、数据线拷贝、或网盘都行。
2. 在手机上点这个 `.apk` 文件 → 系统提示"允许安装未知应用"。
   - 进 **设置 → 隐私保护/安全与隐私 → 特殊权限设置/安装未知应用**，给"微信"或"文件管理"开**允许**。
   - 或直接在弹窗里点"允许此次安装"。
3. 安装完成后，桌面出现「二十八脉」图标，打开即用。
4. 进去后点底部 **「触感」** → 选一种脉 → **按住**大圆钮 → 闭眼把手机贴在指尖/掌心，**这次红米会真震**。

---

## 第三步：以后想更新网页内容
如果你让我改了脉的讲解、加了新功能，我只要更新 `app/src/main/assets/index.html` 这一个文件，你重新走一遍"第一步方法 A 的上传 + 重新构建"即可（覆盖上传 index.html，重新 Commit，Actions 自动重跑，重新下载 APK）。

## 常见问题
- **Q：GitHub 上传时提示文件很多/目录不对？** 确保你是把 `_28mai_apk` 文件夹里的**全部内容**（含 `app`、`build.gradle`、`settings.gradle`、`.github`）一起拖进仓库根目录，不要只拖某个子文件夹。
- **Q：Actions 跑红（失败）了？** 多半是上传时目录结构丢了（少了 `app/src/...` 这种层级）。删掉仓库重传一次即可；仍有问题把红色报错截图发我。
- **Q：安装时提示"有风险/恶意应用"？** 这是安卓对"未知来源"的通用提醒，不是病毒（这是我们自己的开源工程）。按上面开"允许安装未知应用"即可。
- **Q：App 打开是白屏？** 一般不会。若遇到，多半是构建用的不是本工程文件，重新上传覆盖即可。
